# 被留下的人 · 互动叙事原型（L1）

《三角洲：新三角洲剧本》第一章「零号大坝——被留下的人」的可玩网页原型。
对标《隐形守护者》的玩法：静态关键帧 + 文字 + 选择 + 死亡回溯。

## 怎么打开

**方式一（推荐）**：双击 `启动试玩.bat`
会起一个本地服务并自动打开浏览器，存档/继续功能正常。

**方式二**：直接双击 `index.html`
也能玩，但浏览器可能禁止本地文件写入存档，「继续上次」会不可用。

## 操作

| 操作 | 效果 |
|---|---|
| 点击画面 / 空格 / 回车 | 继续（文字未打完时先补全） |
| 1 / 2 / 3 或点击 | 选择选项 |
| ESC | 菜单（继续 / 重玩 / 导演模式 / 静音） |
| D | 导演模式：看当前节点、旗标、隐藏数值，可跳转任意节点 |

## 本版包含

- 第一章全部 6 个小节：门后的枪 / 分别转运 / 地面上的人 / 先走的人 / 那一家人 / 报告
- 4 个主选择、6 个死亡结局、1 条主线合流
- 死亡卡 + 「回溯到选择」；自动存档；章末统计（用时、死亡次数、隐藏倾向）
- 34 个剧情节点，正文全部来自剧本原文（仅做少量分段）
